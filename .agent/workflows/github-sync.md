---
description: Always sync local changes to GitHub
---

Whenever any updates, edits, or file modifications are made to the codebase, ALWAYS run the following commands to ensure the local environment and the GitHub repository are in sync. 

1. `git add .`
2. `git commit -m "Update from Antigravity session"` (Or use a more descriptive commit message if applicable)
3. `git push origin main`
